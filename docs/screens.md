# 画面の設計

番号（①〜⑦）は元の仕様書の画面番号です。

```
起動
 ├─ ① オンボーディング（初回のみ）
 └─ タブ
     ├─ ② ホーム ──────┬─ ⑤ 月次チェックイン（全画面）
     ├─ ③ 一覧         ├─ ④ 登録・編集（シート）─ 解約日の選択（シート）
     ├─ ⑥ レポート     └─ ⑦ ペイウォール（シート）
     └─ 設定 ─ プライバシーポリシー
```

## ① オンボーディング

`OnboardingView` / `OnboardingViewModel`

初回起動時だけ表示する3ページです。スワイプでは進まず、ボタンでだけ進みます（通知の説明を飛ばしたり、フォームの操作でページがめくれたりしないように）。上部に何ページ目かを示す印（●○○）を出します。

| ページ | 内容 | ボタン |
|---|---|---|
| 1. 価値の説明（`OnboardingValuePage`） | 「サブスクを、1冊にまとめて管理」。支払日の前日にお知らせ／毎月・毎年の合計がひと目でわかる／毎月のチェックインで、使っているかを振り返る／登録したデータは端末の外に出ない | はじめる |
| 2. 通知の許可（`OnboardingNotificationPage`） | 「支払日の前日にお知らせします」。支払日の前日 9:00／毎月1日 20:00 の月次チェックイン（登録から1ヶ月後から）／通知は端末の中で作ること | 通知を許可する（許可のダイアログを出してから次へ）／あとで |
| 3. 最初のサブスク（`OnboardingFirstSubscriptionPage`） | 「最初のサブスクを登録」。④の登録フォームを埋め込む | 保存（登録して終了）／スキップ |

終えると `onboarding.completed` を保存し、タブの画面に切り替えます。直後にペイウォールは出しません。無料プランでは、このあとトラッキングの許可のダイアログを出します（[ads.md](ads.md)）。

## ② ホーム

`HomeView` / `HomeViewModel` / `HomeSummary`

上から順に：

1. チェックインのバナー（`HomeCheckInBanner`）：前月分が未回答のときだけ。「8月のチェックイン　3件のサブスクを使ったか教えてください」。タップで⑤
2. 合計のカード（`TotalsCard`）：毎月の支払い（月額換算）、1年あたり、契約中の件数
3. 今月のひとこと（`InsightCard`）：AI または定型のコメント。読み込み中はぼかした仮の文を出す
4. 解約候補のカード（`HomeCancelSuggestionsCard`）：候補があるときだけ。上位3件、4件以上なら「すべて見る」でレポートへ。行をタップで④。無料はぼかし＋鍵
5. 次の支払い（`HomeUpcomingPaymentsCard`）：支払日の近い3件（日付と「明日」「あと3日」、金額は「12,800円/年」のように周期付き）。「すべて見る」で一覧へ。行をタップで④

- 右上の「＋」で④（無料プランの上限なら⑦）
- 無料プランでは画面の下（タブバーの上）にバナー広告（[ads.md](ads.md)）
- 契約中のサブスクがないときは、登録を促すカード（「サブスクを登録して、1冊にまとめましょう」）だけを出す

## ③ サブスク一覧

`SubscriptionListView` / `SubscriptionListViewModel` / `SubscriptionListSections`

- 契約中（件数付き）：並び順を左上のメニューで選ぶ（支払日順／金額順（月額換算）／カテゴリ順）。選んだ順は保存する
- 無料プランでは、下に残りの件数を案内する
- 解約済み（件数付き）：はじめは閉じている。見出しのタップで開閉。解約日の新しい順
- 各行（`SubscriptionListRow`）：頭文字アイコン、名前、金額と周期、次回支払日。タップで④
- 右上の「＋」で④（上限なら⑦）
- 無料プランでは画面の下にバナー広告
- サブスクが1件もないときは、説明と「サブスクを登録」ボタン

## ④ 登録・編集

`SubscriptionFormView` / `SubscriptionFormViewModel` / `SubscriptionFormCancelSheet`

| セクション | 項目 |
|---|---|
| サービス | サービス名（入力中は候補を最大5件表示。選ぶと名前が入り、カテゴリを自分で選んでいなければカテゴリも入る）、カテゴリ（初期値「その他」） |
| 支払い | 金額（数字のみ・7桁まで。全角数字も受け付ける）、周期（毎月・毎年）、次回支払日 |
| 無料トライアル | トライアル中のスイッチと終了日。無料プランでは「お知らせはプラスの機能」と注記 |
| 状態（編集時） | 「解約した」／「契約中に戻す」。解約済みなら解約日を表示 |
| 削除（編集時） | 確認のうえ削除（チェックインの記録も消える） |

- 保存ボタンは、名前と1円以上の金額があるときだけ押せます。押せない理由を支払いのセクションの下に表示します（「サービス名を入力すると保存できます」など）
- 過去の支払日を入れた場合は、今日以降の支払日に進めて保存します
- 無料プランで新しく登録して閉じたときは、閉じた後に全画面広告を出すことがあります（回数のルールあり。オンボーディング中は出さない）
- 保存の時点で無料プランの上限を超える場合（開いた後にプラスの期限が切れた場合など）は、ペイウォールを開きます
- 「解約した」を押すと、解約した日を選ぶシートを開きます。選べるのは登録日から今日まで。1年あたりの金額を「節約として記録します」と案内し、実際の解約手続きは各サービスで行うよう書いています。記録するとシートとこの画面を閉じます
- 「契約中に戻す」は、無料プランの上限を超える場合はペイウォールを開きます
- 解約・契約中に戻す操作の前に、フォームで編集中の内容を保存します
- オンボーディングに埋め込むときは、キャンセルボタンを出さず、保存後も閉じません

## ⑤ 月次チェックイン

`CheckInView` / `CheckInViewModel` / `CheckInQuestionView` / `CheckInCard` / `CheckInCompletionView`

全画面で、前月分が未回答のサブスクを名前順に1件ずつ聞きます。

- 上部：進み具合のバー、「1 / 3」、2件目からは「ひとつ戻る」
- カード：頭文字アイコン、名前、金額、「先月（8月）、◯◯を使いましたか？」
- 答え方：「使った」「使っていない」のボタン、カードの右スワイプ（使った）・左スワイプ（使っていない）、VoiceOver のアクション。ボタンの下に「カードを左右にスワイプしても答えられます」
- 左上：途中は「あとで」、終わったら「閉じる」
- 回答を保存できなかったときは、進まずにアラートを出します（スワイプしたカードは元の位置に戻り、もう一度答えられる）

完了画面：

| 状態 | 見出し | 説明 |
|---|---|---|
| 答えた | チェックイン完了 | ◯件のサブスクを振り返りました。来月もチェックインでお知らせします。 |
| 登録から1ヶ月たったものがない | まだチェックインはありません | 登録から1ヶ月たったサブスクについて、毎月1日に「先月使いましたか？」とお聞きします。 |
| 契約中のサブスクがない | サブスクが登録されていません | サブスクを登録すると、毎月のチェックインで使っているかを振り返れます。 |
| 回答済み | 先月分は回答済みです | 来月1日に、またチェックインでお知らせします。 |

解約候補があれば、「「使っていない」が続いているサブスクがあります」のカードを出します。プラスは「レポートで確認する」でレポートへ、無料は「サブスク帳プラスで確認する」で、閉じた後にペイウォールを開きます。

無料プランで今回1件以上答えて閉じたときは、閉じた後に全画面広告を出すことがあります（回数のルールあり）。

## ⑥ 振り返りレポート

`ReportView` / `ReportViewModel` / `ReportSummary`

上から順に：

1. 「今月のまとめ（2026年9月）」
2. 合計のカード（ホームと同じ）
3. カテゴリ別の円グラフ（`ReportCategoryChartCard`）：中央に合計、下に凡例（色・カテゴリ名・件数・金額・割合）。凡例が表の役割も兼ねる
4. 今月の振り返り（`InsightCard`）
5. 「サブスク帳プラス」（無料はバッジ付き。各カードをぼかし＋鍵）
   - 解約候補（`ReportCancelSuggestionsCard`）：すべての候補と AI の理由。ないときは説明
   - 重複しているサブスク（`ReportDuplicatesCard`）：カテゴリごとに件数・月額の合計・各サブスク
   - 年間節約レポート（`ReportSavingsCard`）：解約で浮くお金（1年あたり）、解約件数と節約累計、「画像でシェア」

共有画像（`ReportShareImage`）は、サービス名を載せず、金額と件数だけを載せます（「サブスクを見直して　1年で 24,072円　の節約になります」）。ライトモードで3倍の解像度で作ります。

サブスクが1件もないときは「まだデータがありません」。無料プランでは画面の下にバナー広告を出します。

## 設定

`SettingsView` / `SettingsViewModel`

| セクション | 内容 |
|---|---|
| サブスク帳プラス（`SettingsPremiumSection`） | 未加入：アップグレード・購入を復元。加入中：プラン・状態・期限・契約の管理・購入を復元、期限の後の説明 |
| 通知（`SettingsNotificationSection`） | 許可の状態（未決定なら「通知を許可する」、拒否なら「設定アプリを開く」）、支払日の前日・トライアル終了（プラスのみ）・月次チェックインの ON/OFF |
| AI（`SettingsInsightSection`） | AIコメントが使えるか（「利用できます」「定型のコメントを表示中」）と理由 |
| 広告（`SettingsAdSection`、無料プランのみ） | 広告を非表示にする（ペイウォール）、トラッキングの許可を変更（設定アプリを開く） |
| このアプリについて（`SettingsAboutSection`） | 利用規約（Apple 標準の使用許諾契約）、プライバシーポリシー（`PrivacyPolicyView`）、バージョン |
| データの全削除（`SettingsDataDeletionSection`） | 確認のうえ全削除。プラスの契約は消えないこと、解約の方法を案内 |
| デバッグ（`SettingsDebugSection`、Debug ビルドのみ） | プラスの切り替え、登録済みの通知の一覧 |

## 表記の決まり

- 金額は「1,490円」、周期付きは「1,490円/月」。年の金額は「1年あたり」と書き、「年間」は使わない
- 「使っていない」は、チェックインの回答であることがわかるように「チェックインで「使っていない」」と書く
- 有料プランは「サブスク帳プラス」、App Store での契約は「契約」と書く（「購読」は使わない）
- AI が使えないときのコメントは「定型のコメント」と書く（「テンプレート」は使わない）
- 解約は「記録する」と書き、実際の解約手続きは各サービスで行うことを添える
