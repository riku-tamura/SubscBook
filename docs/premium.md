# 課金の設計（6章・7章）

有料プラン「サブスク帳プラス」は、StoreKit 2 の自動更新サブスクリプションで提供します。サーバーは使わず、購読状態は端末の StoreKit で判定します。

## 商品

| 商品 ID | 期間 | 価格 | 導入オファー | 表示順 |
|---|---|---|---|---|
| `com.hachimaki.SubscBook.premium.yearly` | 1年 | 2,400円 | 1週間無料（初回のみ） | 1（上に大きく表示） |
| `com.hachimaki.SubscBook.premium.monthly` | 1ヶ月 | 300円 | なし | 2 |

- サブスクリプショングループ：「サブスク帳プラス」（2つは同じグループなので、同時に契約されない）
- ファミリー共有：なし
- ID は `PremiumProducts` で定義します。Bundle ID を変える場合は、`PremiumProducts.prefix` と `Products.storekit` を合わせて変えてください
- `Products.storekit`（リポジトリ直下）は、ローカルでの購入テスト用の定義です。スキームの Run に設定してあるので、シミュレータで App Store Connect なしに購入できます。ストアフロントは日本、言語は日本語です

## 無料とプラスの違い

`PremiumFeature` が機能の一覧（名前・説明・アイコン）を持ち、ペイウォールと鍵の表示で使います。

| 機能 | 無料での見え方 |
|---|---|
| サブスクを無制限に登録 | 契約中5件まで。6件目の追加・解約済みを戻す操作でペイウォールを開く |
| 無料トライアル終了の事前通知 | 登録画面でトライアル終了日は入れられるが、通知は届かない。設定の通知スイッチの代わりに「プラス」バッジ |
| 解約候補の提案 | ホーム・レポートのカードをぼかし、鍵を重ねる。件数だけは見出しに出る |
| 重複サブスクの検出 | レポートのカードをぼかし、鍵を重ねる |
| 年間節約レポート | レポートのカードをぼかし、鍵を重ねる。共有画像は作らない |

ぼかしと鍵は `View.premiumLocked(_:feature:)` で付けます。ぼかした中身は操作できず、VoiceOver でも読み上げません。鍵の部分をタップするとペイウォールを開きます。

AI の月次のひとことは、無料プランでは解約候補・重複の名前（有料機能の中身）を材料に含めません（[ai-insights.md](ai-insights.md)）。

## 購読状態の判定

`EntitlementManager`（`@Observable`、全画面で共有）

- `Transaction.currentEntitlements` から、検証済みで、返金されておらず、期限が切れていない取引のうち、期限が最も遅いものを使います
- `activePlan` に、商品 ID・期限・自動更新するか・無料トライアル中か（導入オファーで購入したか）を持ちます
- `isPremium` が true なら、プラスの機能を使えます（Debug ビルドでは開発用の切り替えも見る）
- 状態を読み直すタイミング
  - 起動時
  - `Transaction.updates` に取引が流れてきたとき（ほかの端末での購入、更新、返金など）
  - アプリがフォアグラウンドに戻ったとき（期限切れ・返金が `Transaction.updates` に流れないことがあるため）
  - 購入・復元の後

## ペイウォール（⑦）

`PaywallView` / `PaywallViewModel` / `PaywallPlan` / `PaywallPlanCard`

表示のきっかけ（`PaywallReason`）によって見出しと説明を変えます。

| きっかけ | 見出し |
|---|---|
| 無料プランの上限（`subscriptionLimit`） | サブスクを無制限に登録 |
| 鍵の付いた機能をタップ（`lockedFeature`） | その機能の名前（例：解約候補の提案） |
| 設定から開いた（`settings`） | 節約をもっと確実に |

画面の構成：

1. 見出しと説明
2. プラスの機能の一覧（5つ）
3. プランの選択（年額が初期選択で「いちばんお得」。年額には「月あたり200円」と、使える場合は「最初の1週間無料」）
4. 購入ボタン（トライアルを使えるなら「1週間無料で試す」、それ以外は「2,400円/年で登録する」など）と、トライアルの後の料金の説明
5. 自動更新の説明（価格・請求のタイミング・24時間前までの解約・解約方法）
6. 利用規約・プライバシーポリシー・購入を復元

- 価格は App Store の商品情報から表示します。日本円の場合は、アプリ内のほかの金額と同じ「2,400円」の表記にそろえ、それ以外の通貨は App Store の表記のままにします
- 商品を読み込めないときは、「再読み込み」のボタンを出します
- すでにプラスの場合は、プランの選択の代わりに「すべての機能をお使いいただけます」と表示します
- オンボーディングの直後にはペイウォールを出しません

## 購入

`EntitlementManager.purchase` → `PaywallViewModel.purchase`

| 結果 | 表示 |
|---|---|
| 購入完了 | 「ありがとうございます」→ OK でペイウォールを閉じる |
| 承認待ち（ファミリー共有の承認と購入のリクエストなど） | 「承認を待っています」→ OK で閉じる |
| ユーザーが取り消した | 何も表示しない |
| エラー | 「購入を完了できませんでした」 |

購入・復元の処理中は、ほかのボタンを押せないようにしています。

## 購入の復元

ペイウォールと設定画面から行えます。`AppStore.sync()` の後に購読状態を読み直し、次の3つを区別して表示します。

| 結果 | 表示 |
|---|---|
| `restored` | 購入を復元しました |
| `nothingToRestore` | この Apple ID でサブスク帳プラスの購入が見つかりませんでした |
| `failed` | 復元できませんでした（時間をおいて、もう一度） |

開発用のプラス切り替えではなく、実際の購入があるかで判断します。

## 設定画面の表示

`SettingsPremiumSection`

- 未加入：「サブスク帳プラスにアップグレード」と「購入を復元」
- 加入中：プラン名（年額プラン・月額プラン）、状態（無料トライアル中）、期限、「サブスク帳プラスの契約を管理」（App Store の管理画面をアプリ内で開く）、「購入を復元」
- 期限の見出しは状態で変えます：無料トライアル中は「無料期間の終了日」、自動更新するなら「次回の更新日」、しないなら「有効期限」
- 期限の後にどうなるかを下に書きます（トライアルの後は自動で有料になること、自動更新がオフなら無料プランに戻ること）

## テストと確認

- 単体テスト（`StoreKitTests`）：`Products.storekit` を読み込んだ `SKTestSession` で、商品定義、購入でプラスになること、期限切れで無料に戻ること、トライアル中の扱い、ペイウォールの購入の流れを確かめます。テスト後に購入履歴を消します（消さないと、シミュレータでアプリがプラスのまま起動するため）
- シミュレータ：スキームの StoreKit 設定で購入できます。Xcode の「Debug → StoreKit → Manage Transactions」で購入を消したり、期限切れにしたりできます
- 開発用の切り替え：起動オプション `-forcePremium`、または設定画面の「デバッグ → プラスを有効にする（購入なし）」
- リリース前：Sandbox アカウントで購入・復元・期限切れを確かめます
